# Ember — Releases

Public download channel for **[Ember](https://github.com/dito-kurkchievi/EmberIDE)**, a lightweight Rust/Floem IDE. The source lives in a private repo; built binaries are published here so the in-app updater can fetch updates without any token.

## Downloads

Grab the latest build from the [Releases](https://github.com/dito-kurkchievi/EmberIDE-releases/releases) page:

- **Windows** — `.msi` or `.exe` installer, or the portable `.zip`
- **macOS** — `.dmg` (Intel: `x86_64`, Apple Silicon: `aarch64`)
- **Linux** — portable `.tar.gz`

Builds are currently **unsigned**, so Windows SmartScreen and macOS Gatekeeper warn on first launch (right-click -> Open on macOS).

## Auto-update

Ember checks this repo on launch and offers a one-click in-app update when a newer release is available.
